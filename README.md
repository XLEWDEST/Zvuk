# Zvuk Desktop

> **⚠️Дисклеймер:**
> Это неофициальный десктоп-клиент и **не связан с сервисом "Звук"**. Название и бренд «Звук» принадлежат
> ООО «Звук» и используются только для указания совместимости.
> Клиент использует недокументированные API-эндпоинты zvuk.com, которые могут измениться или
> перестать работать в любой момент.
> Приложение **не скачивает и не распространяет** музыку: воспроизведение идёт из вашей
> собственной учётной записи, как в официальном приложении.
> Предназначен только для личного некоммерческого использования. Используйте на свой риск
> и соблюдайте Пользовательское соглашение zvuk.com.
> По запросу правообладателя репозиторий и релизы будут удалены.

Лёгкий **НЕОФИЦИАЛЬНЫЙ** десктоп-клиент музыкального сервиса [Звук](https://zvuk.com) для Windows, по духу — как VK Music / Яндекс Музыка.

- Поиск треков, артистов, альбомов и плейлистов
- «Моя музыка»: любимые треки, альбомы и плейлисты с вашего аккаунта
- Просмотр альбомов и плейлистов с полным списком треков
- Полноценный плеер: воспроизведение, пауза, переключение треков, перемотка, громкость, HLS-стримы
- Интеграция с системными медиа-клавишами (Media Session API)
- Токен хранится в Windows Credential Manager (с резервным файлом)
- Низкое потребление памяти: Tauri + системный WebView2 (без Electron)

## Как получить токен

1. Войдите на **zvuk.com** в любом браузере.
2. Откройте страницу **https://zvuk.com/api/tiny/profile** — вы увидите JSON.
3. Скопируйте значение поля **`token`** (без кавычек).
4. Вставьте его в приложение на экране входа и нажмите «Войти».

Токен привязан к вашей учётной записи. С ним доступны полные треки. Без токена можно воспользоваться «Анонимным входом» — будут доступны только 30-секундные превью.

## Сборка и запуск

Требуется: Node.js 20+, Rust (MSVC toolchain + Visual Studio Build Tools с C++ workload), WebView2 (есть в Windows 10/11).

```bash
npm install

# разработка (горячий запуск окна)
npm run tauri dev

# релизная сборка: exe, MSI и NSIS-установщик
npm run tauri build
```

Готовые бинарники появятся в `src-tauri/target/release/bundle/`.

> Приложение не подписано цифровой подписью, поэтому Windows SmartScreen может показать предупреждение — выберите «Подробнее» → «Выполнить в любом случае».

## Управление плеером

Горячие клавиши настраиваются в приложении (Настройки → Горячие клавиши) и работают глобально, даже когда окно свёрнуто в трей. По умолчанию все комбинации отключены.

## Структура проекта

```
ui/                      # интерфейс (HTML/CSS/JS, без сборщика)
  js/app.js              # вся логика фронтенда
src-tauri/
  src/api.rs             # GraphQL-клиент API Звука
  src/commands.rs        # Tauri-команды
  src/store.rs           # хранение токена (keyring)
  src/lib.rs, main.rs    # точка входа
```

## Примечания

- Клиент обращается к GraphQL-эндпоинтам (`zvuk.com/api/v1/graphql`) с авторизацией по заголовку `X-Auth-Token`. Эти эндпоинты не документированы и не гарантируют стабильности.
- Использование неофициального клиента может противоречить условиям сервиса. Приложение предназначено для личного использования.
- Если токен истёк или стал недействителен — повторно получите его в браузере и переавторизуйтесь.
